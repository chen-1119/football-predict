# 旧候选版本继续结算与 65% 目标

模型候选升级后，旧候选的赛前决策仍应等待并绑定对应官方赛果。原结算入口只处理当前 active ledger，因此退休前可以结算的同一合法赛果，在退休后不能补入旧记录。此缺口影响历史样本完整性，不能据此认定修复会提高命中率。

修复范围是为各版本已有决策追加有效官方结果。新决策、试验激活与晋级审查仍只属于当前版本；旧决策、已有结果及审查事件不改写。旧版本的结果不混入新版本分母。重复接收相同赛果不重复结算，非法来源或比赛身份不一致的赛果继续拒绝。
