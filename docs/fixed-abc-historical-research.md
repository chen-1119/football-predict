## 运行

使用支持 `node:sqlite` 的 Node，仓库查询为只读。PowerShell 示例：

```powershell
$env:HISTORICAL_TRAINING_SQLITE_PATH='C:/path/to/historical-training.sqlite'
$env:FIXED_ABC_OUTPUT_PATH="$PWD/outputs/fixed-abc-run.json"
npm.cmd run verify:fixed-abc
npm.cmd run research:fixed-abc
```

输出只能放在本工作树 `outputs/` 内，已有文件拒绝覆盖。复跑必须指定新文件名；相同代码和输入应产生字节一致的输出。请勿提交历史数据库或私有输出。

## 固定口径

- 仅 HAD，固定 canonical source 为 `xgabora/Club-Football-Match-Data-2000-2025:Matches.csv`。
- 按时间从 2023-01-01 至 2025-06-02（右端不含）清单取最新 20,000 场，覆盖清单中的全部联赛；取样不按输赢或是否有赔率筛选。超限和缺失均有明确记录。
- 训练、调参、校准、测试边界分别为 2023-01-01、2024-01-01、2024-07-01、2025-01-01、2025-06-02。实际训练段因清单上限晚于起始边界。
- 特征按预测时点推进，只消费此前已可用结果；跨拟合边界才可用的标签不得进入此前的拟合。底层模型参数固定，仅 C 修正权重在调参段选择，温度在独立校准段选择。
- A 为去水赔率；B 为现有动态球队强度影子模型，不冒称等同当前线上主模型；C 为按质量衰减的赔率与 B 混合。
- C 权重固定候选为 0、0.1、0.2；温度固定为 0.9、1、1.1。不得因最终测试结果修改网格或分段。
- 概率误差使用同一批全部有效测试行；命中率另有三条路线都能唯一判定的共同分母，平票弃权，不默认主胜。各自筛选子集必须对照完全相同比赛的市场基准，不把不同子集横向冒充同组。
- 零样本返回 null，不补 50%；缺失质量不补满分，缺失概率不补均匀分布。身份重复、玩法混合、未来特征、篡改协议直接拒绝。

## 2026-09-07 实测与复跑

固定日历清单 27,287 场，选入 20,000 场（舍去较早 7,287 场），38 个联赛。训练 4,760、调参 5,941、校准 5,087、测试 3,636；另排除 576 场：模型预热 312、质量未记录 169、市场概率缺失 3、跨拟合边界晚到结果 92。上述计数精确相加为 20,000。
