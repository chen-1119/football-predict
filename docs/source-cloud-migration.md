总控历史诊断回执 `outputs/release-oct02/source-diagnostics/receipt.json` 描述 10 月 2 日 19:52 左右的 current/calculator 成功空响应和停售提示；本轮核对其指向的原始 diagnostics SHA-256 为 `55909f3eae91ee0a77f71435f975a9b2fe910c4252ad876bdd0a950cfdac0ec5`。该记录支持历史观察，没有发起新的生产健康检查。其摘要未包含 HTTP 状态和完整原始响应，所以不能人为补 HTTP 200 后冒充本模块的真实端到端分类输入。

`scripts/sourceCollectionDiagnostic.cjs` 要求显式观察时刻、HTTP 200、schemaValid、providerSuccess、非负整数行数。仅 Sporttery 的 current-schedule，在人工／可信适配器核实官方公告和有效时间窗后，成功的零行响应才诊断为 closed。notice URL 只允许 Sporttery 和财政部 HTTPS 主机；URL 白名单及 `verified=true` 本身不完成内容验证，调用方须提交公告核验凭证。

- closed：建议至多每 6 小时观察一次，并在休市结束边界检查；不刷新业务时钟，不清除已有可信快照，不造新比赛。
- available：非空成功；休市公告不能遮盖实际非空响应。
- unknown-empty：未证实公告的成功空响应，保留未知原因，60 秒起指数退避，上限 1 小时。
- failed：网络、schema、业务成功标志或行数失败，使用同样有界退避。
- blocked：403／429／567，至少 6 小时退避，上限 24 小时；只保留记录，不绕过访问限制。
- 显式 Retry-After 可延长等待；超过 24 小时需人工复核。实际 HTTP-date Retry-After 应由适配器转为秒数；本模块不解析响应头。

返回下次尝试建议、失败次数、原因、HTTP 状态、原业务时钟、原 sourceCycleId 与响应哈希（若提供）。运行者仍需持久化原响应与请求／接收时刻、错误码、请求预算和状态转移。模块无副作用，当前未改变任何正在运行的重试。

## 分阶段迁移：保留线上服务和数据库

1. **只读基线**：导出当前来源清单、权限／许可、计时器、请求预算、最新可信 sourceCycleId 与批次哈希；记录失败状态和回退路径。旧通道继续运行。当前首批完成此阶段的报告工具；没有声称完成全部在线清单。
2. **云电脑隔离影子采集**：仅在已授权现有云电脑上配置无生产写权限的独立账号；单实例锁，固定版本，任务超时，按来源退避。原网页／API 用正常允许方式访问；403／567／登录失效就停止该来源并留证。输出只到隔离目录，不覆盖生产数据，不运行 pushCloudSync。优先迁移官方 current／calculator，补充源逐项迁移，未授权源保持关闭。
3. **交接包**：每个来源独立包，包含契约版本、collectorId／版本、sourceCycleId、请求开始／结束、receivedAt、providerPublishedAt／providerUpdatedAt（未知 null）、原文哈希与规范化哈希、源 URL／方法／scope、HTTP 状态、schema、业务成功标志、行数、休市公告凭证、逐字段许可和映射证据。业务密钥与登录状态永不进入包或普通日志。比赛 ID／开球时间／池代码不得仅凭中文名对齐。
4. **受限服务器接收**：总控复用签名 relay/evidence 接口验证 envelope、可信 collector、端点范围、时间、hash、重放与冲突；云电脑不持数据库凭证、sudo、部署或重启权限。先写影子入口，正式发布仍由现有服务器处理并遵守所有门槛；需要新 collector key 的信任注册由总控另审，不在本分支改 deploy。
5. **七天对照**：同时采集旧／新来源，按同一匹配比赛、池、时间窗比较，输出每天报告。单通道拥有正式接收权；跨来源重复观察只更新 lastSeen，不改 providerUpdatedAt、冻结预测或原决策时钟。七天内须覆盖恢复销售和非空赛程；纯休市七天不算完成非空验证。七天完成仅为迁移运行验收，不替代新数据源 7–14 天影子准入或模型校准。
6. **小范围切换与回滚**：总控明确批准后，先切一个来源，保留旧通道可恢复至少七天；切换记录包含前后 collectorId、最后可信 cycle、幂等游标、接收权和版本。未验收不关闭旧通道。

七天验收要求：每个计划周期都有执行／跳过／退避凭证；成功输入原文哈希、来源和接收时钟 100% 齐全；所有来源同场同池对照无未解释冲突，未授权字段数为 0；零数据丢失、零重复正式发布、零伪造业务时钟；保留旧快照；近开赛数据满足现有门槛；故障注入覆盖网络失败、403／567、错误 schema、正常休市空响应、进程重启与重复上传；一次回滚演练证明恢复旧接收权、游标及可信快照，不倒退生命周期、不回填冻结决定。达不到任何项保持影子运行。来源停顿、验签／CAS 失败或未解释冲突触发停止新接收并恢复旧通道，不能靠放宽门槛完成切换。

## 成本依据与未决报价

优先复用已有已付费云电脑，不新增付费 API。仍需获取实际订单中的区域、vCPU／内存、磁盘、镜像、网络、开机时长和剩余额度。试验规格可从单浏览器 2 vCPU／4 GB 起测，若内存不够再评估 4 vCPU／8 GB；这是试验预算假设，不是已测资源需求或采购建议。

云电脑七天按需预算：`168 × 计算小时价 + 磁盘费用 + 镜像费用 + 公网／NAT／流量费用`；31 天持续运行按 744 小时计算。包月使用订单报价，不把停止计算计费当作磁盘／网络免费。[华为云计费项](https://support.huaweicloud.com/price-workspace/workspace_01_0036.html) 和 [定价说明](https://www.huaweicloud.com/product/workspace/pricing.html) 已于本轮查询；没有区域与订单，无法给可靠人民币总价。未购买任何资源。

已有 FunctionGraph 计划：31 天每五分钟共 8928 次，加 100 次测试，按 256 MB／60 秒上限为 135420 GB-秒。`node scripts/huaweiFunctionGraphCostPolicy.cjs` 校验本地规划；不读取实际账单或云端配置。官方免费额度为每月 100 万次请求和 400000 GB-秒，主子账号共享，不能保证该账号当月剩余额度或总账单为零。[官方额度说明](https://support.huaweicloud.com/price-functiongraph/functiongraph_00_0012.html) 本轮查询。旧 README 的九月账单是历史材料，不作为十月价格或余额证明。双跑期间不得重复启动付费采集计时器。

## 复现与待集成接口

从本工程运行：

```powershell
node --test scripts/verifySourceCloudDiagnostics.cjs
node scripts/sourceCoverageReport.cjs RECEIPT_PATH MATCHES_PATH
```

两个路径显式指向总控的已核验线上导出；CLI 不提供默认仓库业务数据或自动网络下载。默认 asOf 使用导出观察时刻以保证同批次重跑一致；可传第三个显式时刻。年龄阈值只用于诊断，不改变正式推荐／发布资格；零比赛时覆盖率为 null，不能输出 100%。

首批无需修改共享文件，因此没有待应用代码补丁。下一步由总控在 `runSyncWorker.cjs`／source adapter 的现有分类之后接入 `diagnoseSourceCollection(input)`，完整成功标志、源 scope、HTTP 状态、原文哈希和公告凭证来自实际响应；持久化返回值后用现有调度器等待。不能把本模块建议用于缩短现有更长的退避，也不能替换现有错误分类或门槛。覆盖报告可由总控在已验证线上导出步骤后调用 `reportFromFiles`；新增补充原文格式或公共 schema 前另提接口评审。
