1. 预打包合同检查实际源/目标实现、门槛、提名策略哈希，并确认声明和专项验证器都列入签名制品清单，在预留发布序号前失败即停止。

4. 切换后，验证所有原账本及候选注册序列的完整前缀、原账本头哈希和旧活动账本各项计数。旧账本必须追加明确退役事件，指向指定目标；新账本不能预先存在，冻结/事件时间不得早于本次基线，新决策证据不得早于新冻结时点，激活窗口必须重新预登记，onlineEffect始终false。
