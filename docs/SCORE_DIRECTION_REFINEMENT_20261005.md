## 本次修改

1. 同向比分只使用与同一冻结 decisionId / recordHash 绑定的比分投影；缺失时显示不可用。全局众数及原研究结算保留在分布参考中，不新增历史比分命中率。
2. 主方向优先显示。让球明确主队让／受让及正负球数；两市场均展示无条件概率，条件伴随占比单独解释。
3. 当前单场质量检查真实冻结主市场的概率、报价和来源时钟。历史 HAD 统计及冻结结算维持原口径，跨轨门槛与模型权重不变。
4. 组合空态显示实际候选、参考、观察计数及返回的筛选原因，不用“没有比赛”解释真实筛选失败。
5. 补齐已核实的 Cyprus、Latvia、Northern Ireland、Georgia、Montenegro、Armenia 六个成年国家队别名，保护青年队、女足及俱乐部边界。它修复样本匹配，不代表训练底稿更新或准确率提高。
