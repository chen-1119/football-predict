# 平局与非热门首选：证据驱动准入和偏置审计

本轮不增加冷门配额，不调高平局概率，不把最高SP当作首选，不宣称未来命中率提高。

## 已修改的逻辑

1. 新HAD决策绑定 primaryAdmissionVersion=verified-unique-primary-v1。完整模型证据、球队样本、时效、来源与真实唯一首选仍必需；不再仅因首选领先第二项不足6个百分点而排除。接近首选保留 close-model-lead 警告。原v2估值风险检查保留，HHAD原门槛不变。
2. 标记进入inputHash及decisionId。没有该标记的旧决策保留旧准入规则；禁止给旧记录补标升级。新决策只在原赛前截止规则内生成。
3. 分类展示优先呈现本身已经是唯一首选的平局或非热门方向，避免近似平局的第二选择遮住真实冷门首选。分类研究仍 researchOnly，不冒充已校准价值策略，不创建第二正式方向。
4. 批次审计将“与市场方向不同”降为诊断，不再单独当成坏输入阻止发布；冷启动大面积同方向、重复概率退化仍拦截。
5. 修复全是市场热门但主胜/客胜分布分散时漏报的监测条件；空BEST样本不再显示成正常分布。赔率相同不以数组顺序指定热门，缺失概率不当0。
6. 新增只读源快照审计，区分市场、校准前、最终模型、旧BEST四个阶段，输出平局、非热门、薄领先与组件分布。报告不是生产访问日志，也不是回测或成绩。

## 评价边界

增加非热门或平局比例本身不会提高命中率。若概率估计可信，以命中为目标应取最高概率；高赔率带来的估值优势是另一个目标。小幅领先可以是真实首选，但没有证据能把它叫“稳胆”。

新策略的覆盖与命中表现须以新冻结样本对照旧策略，同期统计平局召回、三分类混淆矩阵、Brier、log loss和同节点市场基准。本轮不改历史成绩、不复制赛后数据到旧预测。

## 测试与范围

新增单元测试验证三个方向对称、平手拒绝、市场一致性监控、合理非热门批次不拦截、冷启动保护、空样本语义。
新增集成测试使用已有真实算术凭证构建器及发布runtime，验证薄领先平局/客胜能发布并组串、原概率不变、旧策略兼容及哈希保护。内存数据库适配器不代表生产PostgreSQL验收；原生数据库与全构建由既有CI另行运行。
