# HAD 价值平局 / 冷门选择 v1

## 为什么近期正式推荐更偏“正路”

正式HAD过去存在三层结构性偏置：

1. 发布方向固定为完整模型1/X/2概率的绝对第一项；
2. 新版质量闸门会拦截概率领先较薄的方向，而平局/非热门通常更接近第二名；
3. 串关又会从概率向量重新取最大项，即使以后单场改变方向，也可能被组合重新改回热门。

因此“平局/冷门研究”即使在分类研究里出现，也不会进入正式发布和组合。

## 新规则

不设置每天必须出现平局或冷门的数量，也不按高SP自动选冷门。

先计算同一冻结时点的竞彩HAD去水概率。当模型第一方向与市场热门一致时，只有另一方向同时满足独立价值门槛，才允许替换市场热门。

### 平局价值门槛

- 模型平局概率 >= 28%
- 模型概率 - 去水市场概率 >= 4.5个百分点
- 模型概率 × SP - 1 >= 6%
- 与模型第一方向概率差 <= 14个百分点

### 非热门胜负方向门槛

- 模型概率 >= 24%
- 模型概率 - 去水市场概率 >= 5.5个百分点
- 模型概率 × SP - 1 >= 8%
- 与模型第一方向概率差 <= 15个百分点

如果模型本身的绝对第一项就是平局或市场非热门，则直接保留该模型方向，不需要额外“制造冷门”的晋级流程。

市场第一项并列时，不启用反向价值替换。

## 冻结与一致性

每条正式记录保存：

- modelLeader
- marketLeader
- selectionClass
- 三项模型概率
- 三项去水市场概率
- 选中方向的市场偏差
- 模型EV
- 与模型第一方向差距
- 使用的阈值

该证据进入冻结输入哈希。赛后不能改变方向或把未发布研究补成正式记录。

HAD单场、2串1/3串1和复盘读取同一冻结tipCode。组合不再重新从概率向量取最大项。

## 复盘

新增冻结选择类别：

- market-favorite
- model-draw
- model-underdog
- draw-value
- underdog-value
- legacy

每类分别统计已结算数、命中数、命中率、Brier、LogLoss、市场基线和冻结SP下的单位收益诊断。

这些统计只描述真实冻结记录。它们不会自动规定以后每天必须有多少冷门。

## 验证边界

当前滚动校准样本仍不足以证明新规则提高未来命中率。因此本策略的作用是消除“只能选概率第一热门”的结构性限制，并建立可审计的平局/冷门正式样本。

后续是否收紧、放宽或停用各门槛，只能基于新的时间前推冻结样本决定，不能根据赛后结果反推当天方向。
