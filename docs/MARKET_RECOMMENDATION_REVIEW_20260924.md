# 足球推荐逻辑对标与本轮修复（2026-09-24）

## 公开可核验的市场做法

- [Opta](https://theanalyst.com/articles/opta-football-predictions) 用赔率和球队实力评级估计胜平负概率；[评级方法](https://theanalyst.com/articles/power-rankings-your-club-ranked)包含 Elo、赛果与可用的 xG，但单场融合权重未公开。
- [Forebet](https://www.forebet.com/en/faq) 将模型概率与赔率比较，并把价值选择与较高概率的精选分开。其约 50% 的精选展示条件是产品规则，不是可直接复用的校准结论。
- [Dixon–Coles](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/1467-9876.00065) 提供基于球队动态表现的进球分布建模路径，可用于保持比分、胜平负和让球推导的一致性。

这些来源均不能证明某个固定权重或低 SP 排除规则会提高本系统的命中率。赔率包含利润空间，市场概率比较应使用同一时点完整盘口的归一化倒数，而不能把单个 `1/SP` 当作真实概率。

## 当前系统与已修复的问题

系统已有官方 SP 去水市场基线、Elo／近期状态／Poisson 融合、比分反馈、影子候选及赛前冻结。不能将赔率市场或三个相关模型输出再当成多份独立证据：`final` 已使用 Poisson 和比分反馈，`scoreImplied`、`poisson` 也共享进球模型输入。过去的独立一致度可因此虚增置信分数，但不能提供新信息。本轮保留概率和方向，改为只计一个相关模型家族；内部一致度仍用于诊断分歧，不再给“独立一致”奖励。

另外，评估层已将模型第一、第二方向差过小标为 `model-separation-too-thin`，临场发布层此前只展示警告。本轮把它加入临场硬门槛，使这类新候选继续参考展示，但不产生新的临场正式发布。已冻结的方向、玩法、SP 和证据不重写。

## 后续如何判断权重是否真的更好

离线质量报表现在按冻结推荐方向以及模型与市场领跑方向的同意／冲突／市场平手分组，逐组比较命中率、Brier、Log Loss、市场基线、结算覆盖与独立比赛日。所有分组只使用同一批有效赛前发布且已结算的事件；报表不会自动晋级模型。

本轮干净仓库的本地归档没有可用的严格同窗、已结算模型－市场配对行，因此不能据此重新拟合融合权重或宣布命中率提升。要引入新权重，必须先在赛前冻结候选版本、模型概率、完整官方报价及其观察时钟；随后用独立赛果，在不交叉的比赛日滚动比较市场、现行模型和候选模型。正式推荐仍须通过原有风险与晋级门槛，无合格候选时保持参考／观望。
