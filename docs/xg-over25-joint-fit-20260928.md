# xG 与大小 2.5 球联合拟合

## 接入与计算

`sync:prematch` 对当前赛程读取已完赛历史，按主客队名称分别选最近 12 场，生成 `externalSignals.goalFitEvidence`。入选历史结果必须有明确的结果来源与赛后观测时间；xG 还必须来自标记为赛后观测的统计记录，并有独立的统计来源及观测时间。所有时间都必须早于该场预测的观测时间、停售时间和开赛时间。事件号、开赛时间、主客身份、行内容及摘要绑定同一个哈希。缺失、晚到、冲突或样本不足时不会用零值代替。

每队至少有 8 场合格比分、5 场合格 xG。两队历史 xG 的攻防均值形成主客预期进球；两队历史大 2.5 球发生率平均后，通过 Poisson 总球概率的单调反函数得到目标总进球率。原进球率总量的 60%、xG 总量的 18%、大小球历史目标的 22% 联合拟合，总量变化最多 0.35 球；主客份额以 28% 的 xG 权重调整，最多变化 0.08。拟合后的两项进球率同时生成比分矩阵、胜平负/让球比分边际、大小 2.5 球与双方进球概率。

启用时基础版本为 `independent-elo-form-poisson-v14-joint-goals`，未开售版本为 `model-only-no-official-sp-v5-joint-goals`；现有统一后验版本保留，并附 `baseModelVersion`。`joint-goal-fit-v1` 内容哈希、输入样本、算术用量回执及独立回放源码指纹随模型冻结。对启用场次，大小球概率直接由同一 Poisson 进球率产生，避免额外独立平移后与比分矩阵不一致。未启用场次保持旧逻辑与版本。

## 数据边界

此处的“大小球”输入是历史比赛的 **大 2.5 球频率**，不是同场大小球市场报价；不能把它称作盘口去水概率。现有正式采集链路尚无可用的同场大小球报价，xG 历史统计覆盖率也取决于带独立观测时间的真实赛后数据。没有满足门槛的场次继续沿用旧模型。内容哈希保证本地回放绑定，不能单独证明第三方来源真实；正式源校验仍需依赖采集回执与授权数据源。

合成测试覆盖双输入变化、缺失时回退、结果与统计晚到、事件身份及内容篡改、比分与大小球概率一致性、官方 SP 和未开售两条路径。测试不代表线上覆盖率或命中率提升。服务端需要完成仓库规定的签名发布流程后才会运行新版预测链路，合并到主分支及 GitHub Pages 发布本身不等于服务端更新。
