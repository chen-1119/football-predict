# 65% 目标：数据修复与同场候选对照

目标继续按赛前冻结的胜平负单选计算，比分、总进球、让球和双选分开统计。本轮没有把 65% 当成已实现效果，也没有按赛后结果改方向、删失败或缩小推荐分母。

## 本轮修复

- 补充官方赛果可以进入推荐结算。复用既有赛事官方来源校验，严格绑定比赛、开球版本、常规时间比分和实际观测时钟，保留完整凭据与哈希。只用于结算与复盘，不进入在线让球校准或正式模型晋级。
- 真实线上冻结记录 `2041558`（安养 FC—蔚山现代，2:1）的客胜推荐，离线回放由待赛果变为未命中。118 条冻结决策哈希不变；这是本地回放，生产写入为 0。
- 新增固定五候选的离线配对诊断：原模型、原市场及三种固定融合。所有候选使用同场、同时间的冻结概率和相同结算样本，保留未知输入、待赛果、争议和覆盖率。报告只诊断，不拟合、不选出上线赢家。
- 补齐斯洛文尼亚、爱沙尼亚、北马其顿、秘鲁、罗马尼亚的精确成年国家队别名。真实历史资产分别有 317、549、306、714、766 条 Elo 样本，近期输入各可读取 12 条。青年、女足、B 队不能借用；含义有歧义的“爱尔兰”仍保持未解析。别名策略版本更新为 v8，未修改历史资产、观测时间或概率权重。

## 目前证据

2026-09-26 23:28 北京时间导出的 118 条最终冻结决策均来自 `unified-poisson-bayes-v75`。原线上可结算队列为 74 场、8 个竞彩日；原模型 40/74（54.05%），同场市场 41/74（55.41%）。固定融合最高为 43/74（58.11%），只比市场多 2 场，概率误差仍未超过市场基准。这不是独立留出验证，不能据此换权重或宣称达到 65%。

48 条决策有完整输入证据，70 条缺少该证据，应保留为未知。13 条出现某队样本未过新门槛却仍赋予相关模型正权重；其中已结算的 5 场，原模型和市场均命中。因此准入缺陷需要修复，但不能断言它造成了当前队列的命中率下降。PR #84 已修正双方样本准入，新版本需要从实际发布后的独立比赛继续验证。

补充安养 FC 一场后的本地回放是模型 40/75（53.33%）、市场 41/75（54.67%）；固定融合最高 43/75（57.33%）。原始 75 条赛果事件完整保留，新增 1 条，重复回放新增 0 条。两个报告分别保存在 `outputs/frozen-had-candidates-20260926-live-ledger.json` 与 `outputs/frozen-had-candidates-20260926-local-supplement.json`，不得把本地补结算后的数字称作当前线上结果。

## 尚缺的赛果

另有 25 场旧比赛仍缺最终赛果。09/18–09/26 的 72 份服务器原始快照中，可找回全部 25 场签名有效、球队和开球版本一致的赛程身份，但没有对应最终比分。仅凭当前缺失不能断言数据源没有赛果。

已从体彩官网当前开奖页和静态脚本确认：`getUniformMatchResultV1` 的 `matchPage=0` 是最新开奖，历史日期查询使用 `matchPage=1`。正常查询 09/18–09/20 的第一次请求返回 HTTP 403 WAF 页面，随后停止；没有把拒绝响应当成空赛果，也没有回填输赢。

历史补查应独立于每 15 秒快赛果通道，限日期、页数及目标比赛，保留真实收到时钟；恢复访问后再按已验证赛程绑定赛果。当前修复并未解除外部访问限制。

## 接下来如何验收

1. 新版本上线后核对真实读取的球队样本及来源，按新版本另起统计，旧冻结记录保持原样。
2. 将补齐赛果后的模型与市场重新放在同一队列比较，完整披露未结算数。补录结果只能改善完整性，不能叫作预测能力提升。
3. 只有时间隔离的验证和之后的前瞻比赛支持改动时，才调整概率融合、平局校准或冷门选择；继续同时检查命中率、Brier、LogLoss、竞彩日与覆盖率。
4. 达到 65% 的数值、样本是否充分、正式模型是否可发布分别报告，代码和 CI 通过不代表命中率目标完成。
