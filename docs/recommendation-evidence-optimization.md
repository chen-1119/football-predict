# 推荐证据与研究统计优化

## 行为变化

- 胜平负仍取发布模型概率最高项；让球继续使用现有完整比分矩阵及条件伴随分析。没有更改串关玩法、SP 门槛或已冻结方向。
- `baseline-ensemble-policy-v2` 要求 Elo 两队分别至少 6 场，近期状态两队分别至少 8 场且置信度至少 0.25。缺失、非法或单侧样本不再触发对应的高样本混合分支。各分支原有权重保持不变。
- 基础模型版本为 `independent-elo-form-poisson-v12`，最终统一模型版本为 `unified-poisson-bayes-v76`，并保留 `baseModelVersion`。每次混合的策略、分支、实际样本、门槛及权重写入算术凭据；凭据核验会检查策略与样本、权重是否一致。这些权重仍是未验证的启发式基线，不代表训练获得的最优参数。
- 新发布决策增加 `supplementaryPolicyVersion` 与 `supplementaryResearch`，一起进入输入哈希、决策 ID 和不可变记录哈希。只有具备有效 v3 比分矩阵的记录才生成研究首选。
- 比分首选：与已发布胜平负及让球伴随方向一致的比分中，取无条件概率最高项；同概率按主队进球、客队进球升序。其概率不在筛选后的比分内重新归一化。
- 总进球首选：聚合完整比分矩阵的 0–6、7+ 桶，取概率最高桶；同概率取更低桶。7+ 包括全部七球及以上比分。
- 两项首选都未绑定官方 CRS/TTG SP，只作研究，不进入正式推荐或串关，不生成 EV、收益或 ROI。
- 页面统一参考/观望/价格不支持标识；未验证模型不会显示为正式验证通过。超过 15 分钟或未来时间的 SP 显示待更新，截止后的记录仅供复盘。

## 统计口径和兼容性

赛前发布时冻结首选，赛后仅由统一的官方赛果事件结算。待赛果、无效和争议记录不计入命中率分母。官方高版本更正会更新结算结果，原始首选和记录哈希保持不变。

复盘新增比分及总进球两套独立的发布数、待赛果数、结算数和命中率。统计取每场截止前最后一个真实发布版本，与胜平负单场版本口径一致。页面注明全台账范围，不把下方分页或筛选当成这些统计的分母。

历史记录没有新字段仍按原哈希验证和结算，仍可展示原比分矩阵。它们不会回填新的研究首选，也不会加入新增命中率分母。缺乏完整矩阵的新记录也不纳入；排除数单独展示。无需数据库结构迁移，新增字段保存在原决策 JSON 中。

## 验证与发布边界

新增回归覆盖双侧样本边界、实际预测混合和凭据、历史记录、篡改拒绝、7+ 结算、官方结果更正、无效/争议、运行时及前端/分页复盘解析。

这次修改建立可前瞻验证的记录与统计，不宣称提高命中率。后续模型权重调整仍需既有 shadow、独立比赛日和 holdout 验证流程；正式 CRS/TTG 推荐仍需要带来源和采集时间的官方 SP 接入。
