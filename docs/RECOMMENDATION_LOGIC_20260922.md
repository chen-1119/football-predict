# 推荐逻辑与一致性修复

## 同一场比赛只使用一条当前发布记录

今日推荐、赛程、详情的方向、概率、SP、模型时间和发布时间均读取同一条已发布记录。缺少记录时等待发布，不用旧 BEST、GPT 文案或旧预测补位。正常采集可以在截止前追加新版本；历史决策、已冻结串关和赛果不回写。

2026-09-22 15:36 北京时间只读快照发现，维冈竞技及诺茨郡的旧预测为平局、1-1，而当前发布记录为主胜。详情原先仍把旧 1-1 放在比分首位，并在部分解释区引用旧概率。这是混用记录造成的矛盾；此次不调高主胜概率，也不根据用户表达改变推荐。

## 实际执行顺序

1. 检查竞彩日、比赛身份、开赛及销售截止时间。使用当前周期的 prospectiveForecastInput；已结束、停售、身份冲突或超过截止时间的输入不能发布新赛前推荐。
2. 读取当前模型最终胜平负三项概率并归一化。模型距开赛两小时内最多允许一小时旧，六小时内最多三小时旧，其余最多十二小时旧。缺失、过期、时间或比赛身份不一致则等待更新。
3. 取三项概率中唯一最高项作为胜平负首选；完全并列不发布。SP 高低、旧文案、用户偏好不会在发布阶段覆盖该方向。SP 用于展示、市场对照及期望值计算；发布报价必须来自可核验的同场记录且在十五分钟内。
4. 让球使用该场实际官方整数让球数 h，按“主队进球－客队进球＋h”判断让胜、让平、让负。使用与最终胜平负概率一致的比分分布，仅在首选结果成立的比分中计算伴随方向。缺少有效官方让球数、来源身份不符或有效记录相互冲突时，不生成新让球伴随建议。
5. 详情的首位比分仅从已有补充分布中选取符合已发布首选的最高概率比分。没有同向比分则显示暂无；其他结果可以列为备选。该补充分布未绑定本次发布，不作为冻结比分证据或命中率依据。
6. 输出保留参考／影子标记。概率最高只表示相对首选，不表示已超过 50%、已通过独立验证或值得投注。模型验证、报价可用性和串关门槛仍分别检查，不为凑组合放宽条件。

## 平局与让球示例

| 胜平负首选 | 主队让球 | 首选成立时的让球结果 |
| --- | --- | --- |
| 平局 | -1 | 让负 |
| 平局 | +1 | 让胜 |
| 主胜 | -1 | 赢一球是让平，赢两球及以上是让胜 |
| 客胜 | +1 | 输一球是让平，输两球及以上是让负 |

“平局＋主队 -1”的让负条件占比为 100%，意思是平局一旦成立便一定让负，不是这场让负实际有 100% 命中率。让球独立概率必须汇总全部可能赛果，不能把条件占比当作独立概率或用于独立串关概率连乘。
