# 四玩法独立首选与进球分布修正

基于 PR #94 的 `3b78e1d99a6ac90ba817e2f2079a0fb0ca322555`。只修改代码、测试和文档，未运行采集、迁移、生产发布或历史推荐回填。

## 行为变化

| 项目 | 之前 | 新发布记录 |
| --- | --- | --- |
| 胜平负 | PR #94 的概率/价格选向；并列时缺席 | 保留价值覆盖规则；并列用固定顺序选一个方向并降为低置信 |
| 让球首选 | 条件让球方向作为页面首选；部分场次显示“不追让球” | 按 `overallProbabilities` 的最大项给唯一首选，SP、EV、展示、结算使用同一方向 |
| 条件让球 | 容易被当作独立命中率 | 只在展开说明中解释“胜平负首选成立时”的净胜球分布 |
| 比分 | 在胜平负与条件让球同时成立的集合中选一个比分 | 从完整比分矩阵选最高概率比分，不强制与其他玩法首选同时命中 |
| 进球数 | 从全矩阵累计 0～6、7+ | 保留完整累计；比分与进球数均冻结唯一首选 |
| 弱证据 | 观望文案，可能被理解为没有方向 | 保留已有唯一方向并明确低置信；独立串关的准入条件继续生效 |
| 无让球资料 | 比分与进球数一起缺失 | 有冻结进球率时仍生成比分、进球数；不会虚构官方让球线 |

输入无效、盘口未知、没有进球率、身份冲突、已截止不是“低置信证据”，不能通过补造数据解决。新逻辑保留这些必要校验。比分和进球数没有官方 SP 时仍显示首选，但不捏造 EV 或作为正式计价串关腿。

## 进球模型

- 基础模型升级为 `independent-elo-form-poisson-v13`。
- 移除近期数据混合、联赛数据混合、进球校准和进攻意图调整中 3.4～3.8 的单队进球率硬上限；保留原有证据权重和基础先验，不无依据抬高普通比赛的进球均值。
- 单队率 12 是数值支持边界，不是预设足球均值。枚举直到剩余单队质量不超过 `1e-12`，不再固定停在 5、8、10 球；总进球 7+ 包含全部尾部。
- 冻结计算用原始进球率，展示时才四舍五入，避免按两位小数重新构造另一份矩阵。
- 新让球记录标记 `scoreSupportPolicy=adaptive-tail-v1`。旧记录继续用原来的枚举策略复算，原记录哈希和比分不变。
- 没有引入平局、大比分或让胜配额。测试中的强势主让3球可选让胜，弱势主让2球仍可选让负。

本次未新增 xG、大小球、亚洲盘数据采集或训练好的联合拟合器。它们是否实际参与进球率仍由现有输入链路和回执决定，不能把“页面存在这个字段”写成“已用于模型”。未来接入需要可验证的赛前时点、字段语义和同场绑定；本次也没有宣称命中率或收益已提升。

## 冻结与兼容

- `primaryPickPolicyVersion=independent-market-primary-v1` 明确新版正式让球口径。
- `supplementary-research-v2` 冻结全局比分首选及总进球首选；v1 保留原同向比分。
- `had-direction-selection-v2` 记录并列处理规则；旧 v1 按原规则验证。
- `scoreModelInput` 和新策略版本参与输入哈希、决策 ID 和完整记录哈希。
- 赛后独立让球首选单独统计，旧条件让球样本不混入新版分母。
- 新核函数加入发布包清单和独立重放的源码指纹检查，CI 执行新增回归测试。
