# 云端研究接管：实施合同

本批按“现有更新上线 → 服务器档案与接口 → dot 云端验证 → 停本地重复调度 → 关机验收”推进。

## 1. 当前接口源码

- `GET /api/operator/research/day?date=YYYY-MM-DD`：按竞彩日列出 PostgreSQL 原发布批次和 ACK 状态。仅列出不等于验签通过。
- `GET /api/operator/research/artifact?key=reviewed-analysis-...`：在同一只读 RR 事务内读取原始 JSON 文本、原始字节长度与 SHA，运行既有官方签名输入/冻结记录/第二事务 ACK 回放后返回。
- 沿用现有账号会话，仅 operator/admin 可读。匿名401、普通账号403；POST405；私有 no-store。没有新增凭据、角色、公开私有档案或数据库迁移。
- 缺失 ACK 明确返回 `record-present-ack-missing`。查询失败或找不到记录都不构成自动重试发布许可。
- 此接口只覆盖已正常发布时保存的原研究和签名输入。未发布的20/21点独立报告、今天新官方报价和受控提交入口尚不由本批提供。

## 2. 后续服务端闭环

1. 独立时段报告使用创建后不可覆盖的档案，以业务日、报告类型、真实生成时刻和内容 SHA 唯一标识；旧档案导入按实际原字节校验，不补造历史。
2. 新报价由服务器现有采集通道提供完整验签材料、身份及观察钟；dot 的500页面研究作为补充来源，不能签成官方SP。
3. 提交接口只接结构化研究草稿及确切 hash。服务端沿既有 publisher 重新核当时官方签名、事件身份、截止、单场重复、COMMIT和ACK；未知提交先读回。
4. 发布与部署互斥必须由服务器执行；不能仅依赖 dot 提示词或启用第二 writer。受控写入口的源码/部署证明尚未完成前，读接口不开放写方法。

## 3. 接管与关机验收

dot 两个原任务保持暂停直到云端完成：真实生产HTTPS读取、正常登录权限、今日去重档案逐hash核对、完整签名报价验证、正常提交接口能力与失败状态读回。旧云端代理403不绕过。

随后记录唯一接管时间和最后报告键，暂停本地 automation-5/7，确认旧执行及排队任务结束，再启用原云端任务ID；服务器采集器保持独占。本地工程部署按需执行，不作为日常依赖。

关机验收需真实离线区间：本地触发已停且本机离线，服务器完成新的自然采集周期，dot 在云端完成计划巡检和报告归档，回执证明仅一次执行。未发生真实离线区间不能写“关机验收通过”。

## 4. 完成证据

依次记录代码提交、CI、签名包、生产完成回执、自然周期、HTTPS/私有页面、云端独立读回、任务交接和离线区间。任何前一步完成均不替代后一步。Pages 发布结果不作为生产服务器验收。
