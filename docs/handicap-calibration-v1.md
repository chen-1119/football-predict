# 盘口强度分组自动校准 v1

## 分组

冻结让球样本按盘口强度与胜平负背景分组：

- 主让1、主让2、主让3+
- 主受让1、主受让2、主受让3+
- 每个盘口桶再按当时统一HAD首选：主胜 / 平 / 客胜

例如用户关心的“大让球总是让负”主要观察：
- home-give-2|straight:1
- home-give-3plus|straight:1

## 学习信号

每个已结算样本保留：
- 冻结时原始Poisson让胜/让平/让负概率
- 冻结盘口
- 统一HAD首选
- 官方90分钟最终比分
- 实际HHAD结果

计算每个方向的平均原概率与实际频率差值。正的“让负偏差”表示模型历史上给让负的平均概率高于实际让负频率。

## 防过拟合

不使用同一场比赛的赛果修正它自己的预测。当前竞彩日完全排除在校准样本之外。

每组至少18个已结算冻结样本才进入验证：
- 按发布时间排序
- 前约75%拟合残差
- 后至少6场作为时间前推holdout
- 残差单方向最大绝对修正12个百分点
- 再按样本量进行收缩，最大权重65%

只有同时满足：
- holdout Brier至少改善0.002
- holdout LogLoss不恶化超过0.01
- holdout方向命中率不下降超过2个百分点

该组才标记active并影响后续新比赛。否则仅展示复盘，不改变新方向。

更具体的“盘口+HAD首选”分组验证通过时优先使用；否则回退到对应盘口大组；大组也未通过则保持原Poisson分布。

## 方向变化

自动学习调整的是三项概率，不是写死“让负改让平”或“主胜改让胜”。

例如主让2、HAD主胜的历史样本显示模型系统性高估让负，且样本外验证通过，系统会降低让负概率、提高历史低估方向。只有修正后让平或让胜成为概率最高项，才改变新HHAD首选。

所有应用过的校准保存：
- profileHash
- 盘口分组key
- shrinkage weight
- residual vector
- holdout metrics

因此每个新方向可追溯。校准配置变化会生成新的统一decision版本，不覆盖旧冻结结果。

## UI与复盘

赛后复盘页新增“盘口强度分组复盘”：
- 样本数
- 是否已启用
- 让负概率偏差
- 实际让负率
- holdout Brier 原始→校准
- holdout命中率 原始→校准

未达到样本门槛显示“观察中”，不会为了尽快纠偏提前上线。

## 边界

该模块只优化HHAD净胜球概率，不修改HAD方向、2串1/3串1门槛或官方赛果规则。它建立可验证的反馈闭环，但不保证未来命中率或收益。
