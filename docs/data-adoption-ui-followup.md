# 数据采用与缺口：后续 UI 修复

2026-09-07。本文件记录 r694 封包之后的独立补丁，**不在 r694 内，不是上线证明**。

## 修复边界

- 近期状态与 Elo 的样本存在，不再覆盖来源冲突、晚到或陈旧状态。更严格的历史时序问题仍可提高警示级别。
- 观测时钟要求真实日历日期和明确时区；兼容已有北京时间 `YYYY-MM-DD HH:mm[:ss]`。2 月 30 日、无时间的日期、浏览器相关格式不再提供时效证明。原始冻结记录不被修改，只改变展示校验。
- 折叠摘要显示冲突、晚到、陈旧、缺失、待核验和当时未公布的非零数量；每类输入只计一次，合计与全部12类输入一致。
- “有证据但采用未证实”也进入待核验数量，不因接通来源就标记已采用。摘要不计算采用率、置信度或命中率。
- 手机端计数换行，长版本完整换行，支持原生键盘展开/折叠；颜色只辅助，不代替警示文本。
