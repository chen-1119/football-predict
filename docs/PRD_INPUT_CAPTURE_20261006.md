# P0：发布输入时钟与逐市场诊断

## 修复范围

基线 `d041cd09242c0545de16f27b84d9d191c34912bd`。原发布器在异步 PG 与行情读取前保存 `now`，随后读取持续更新的快源。若读取期间刚取得新报价，其取得时间可能晚于旧 `now`，正常未来时间门会拒绝该报价。合成的可控延迟回归在旧实现上真实出现此问题；这证明代码存在竞争路径，**不证明此前每次线上 HHAD 消失都由此引起**。

`Repository.currentInputs` 在 PG/行情/快源读取完成后捕获真实系统时间。发布、串关及研究消费者重新检查该时间，不能把载荷声称的时间当作系统时钟。正式评估在历史/结果读取完成后再次使用真实时钟，所有报价时效、未来时间、模型有效性、销售状态和最早截止规则仍执行；保存及串关冻结前继续检查实际截止。

## 冻结与诊断

每次取数生成 `current-input-capture-v1`：开始/实际完成时间、原 PG 输入 hash、行情输入 hash、合并结果 hash，以及官方让球摘要。新决策把摘要及 hash 绑定到 inputHash、decisionId 和 recordHash；旧记录没有该字段时继续原字节规则，历史原件不更新。

官方摘要保存完整源解析载荷 hash、采集承诺 hash、实际端点时间及采集周期，区别缺源、过期、未来取得、验签失败、事件歧义、球队/日期冲突、停售、缺盘口、截止和成功采用。两端点必须来自同一非空、无边缘空白且与各自已签承诺一致的周期。

摘要最大 16 KiB UTF-8；文本字段最多 255 UTF-8 字节，样本最多 32 条。统计计数不把端点的 512 行上限误当作 PG current 行上限。未知巨大字段和额外键不能进入有效冻结摘要，非开放行的诊断也不能挤掉其他合资格事件。

摘要是重放定位工具，不是新数据源认证、模型校准或正式准入凭据。采集签名不是提供方签名；原模型概率和市场选择规则保持原计算。已有 HHAD 概率较宽导致集中选择的问题仍需独立模型、分玩法评估与样本外验证。

固定 Node 22.22.1，同六文件最终独立回归 **35/35，零跳过**；执行前后七个代码/测试文件 hash 一致。覆盖真实合成 Ed25519 签名、读取期间更新、真正未来报价、跨截止、时钟倒退、空白/超长周期、不同端点周期、诊断篡改、多字节长度与超过 512 条 PG 诊断。无采集旧本地比赛或生产写入。

更广推荐回归保留原日志：489 项，486 通过、2 失败、1 条私有生产导出用例跳过。两失败在隔离 d041 基线的相同两文件再次执行也复现（54 项，52 通过、2 失败），分别为旧平概率处理期待与已更新冻结 HAD 提示文案期待。它们未作为通过，本文不宣称全仓回归或 lint 通过。
