# 胜平负与让球一致性伴随逻辑 v2

## 为什么“主胜 + 让1让负”需要修正

在独立HHAD三项概率里，主让1的让负包含“主队不胜”的全部比分；因此它可能因为合并了平局和客胜而成为全局最高项。数学上这与“主胜是HAD三项中的单项最高”并不矛盾，但把二者同时展示为两个首选会造成产品语义冲突。

新版将卡片上的“让球首选”定义为：**在胜平负首选成立条件下，净胜球分布对应的伴随让球方向**。

## 一致性规则

- HAD主胜 + 主让1：只可能让平（净胜1）或让胜（净胜2+）；让负结构性概率为0。
- HAD客胜 + 主受让1：只可能让平（客净胜1）或让负（客净胜2+）；让胜结构性概率为0。
- HAD主胜 + 主让2：可以出现让负，因为主队净胜1球仍然是主胜，但无法覆盖-2。
- 更大整数盘口按同样的净胜球条件推导。

独立HHAD全局分布不会删除。若其全局最高项与伴随首选不同，详细分析区会显示“独立HHAD全局最高项”，但不会把它当作顶部伴随推荐。

## 概率含义

顶部让球百分比改为“条件占比”：条件是冻结的HAD首选成立。它不是独立HHAD命中率，因此UI会明确标注。

## 自动学习

handicap-calibration-v2 只使用：
- 真实冻结的v2伴随方向；
- 官方90分钟赛果；
- 且该场HAD冻结首选实际命中的样本。

这样校准学习的是“主胜成立后，是卡盘还是穿盘”等边际分布，不会用HAD主方向本身失败的比赛污染伴随让球校准。仍保留最少18场、至少4个比赛日和时间前推holdout门槛。

## 复盘

让球伴随首选仍按实际HHAD结果单独结算。复盘命中率统计所有已发布伴随首选；自动校准训练集则只使用HAD主方向实际命中的子样本，两者口径在UI中分开说明。

2串1、3串1仍使用HAD唯一首选，不改变SP门槛或既有串关冻结规则。
