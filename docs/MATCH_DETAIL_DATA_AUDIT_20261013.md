## 修复范围

- 详情在同一个数据库只读快照内核原始记录、签名输入、ACK 和精确事件身份，再提供已发布证据；客户端同时检查事件版本与开球时间。
- 总统计合并真实发布来源，保留各来源独立分母和原结算门槛。
- 自然结算只接入与事件身份完全匹配的发布记录，保留原官方 90 分钟赛果校验。
- 缺项展示采用“未核实/未取得”，保留来源与时间，不将未知降为零风险。
- 删除已无入口的三个旧世界杯页面/组件，保留实际使用中的底层数据及校验。
