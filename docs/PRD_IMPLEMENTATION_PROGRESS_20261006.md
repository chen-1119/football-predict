## 这些结果可用于什么

身份绑定修复对应“列表能看到、别名详情打不开”的代码路径。采集时钟修复了可重现的异步读取竞态，并保留每批准确诊断；尚未证明它是此前线上让球报价波动的唯一原因。必须部署后再用真实 API、自然 worker 新周期和 Chrome 验收。

5,320 条社区赛果提供研究标签和入库工具。来源过去的可用时刻未证明；默认严格历史 as-of 查询排除这些派生行。国家队、官方 SP、亚洲盘及五个时点的真实报价覆盖为 0；这批数据没有训练模型，也不能用于正式结算或宣称历史预测优势。

## 后续按依赖推进

1. 正常签名发布 P0 服务端修复，验收完整源码/dist、PG 代际、自然 worker、别名详情和历史冻结连续性。
2. 从现在开始追加真实官方报价观察，保存玩法、让球数、完整同源报价、来源观察/接收时间、事件和球队身份。初次观察不冒充开盘；收盘报价只作独立 CLV 目标。现有观察链继续复用，未接入的独立 HHAD 适配器保持研究状态。
3. 为当前赛事补齐国家队历史、明确球队映射、阵容/伤停/负荷、实测 xG、同公司 AH 轨迹。未知保持 null，不以赔率补出球队证据。
4. 用既有零市场训练及影子评估工具，按时间分训练、校准和样本外测试；与同场同刻市场对照，并逐因子消融。Brier 的绝对阈值不能替代胜过市场和覆盖审查。
5. 冻结前瞻纸面推荐、结果修订和 CLV；至少覆盖预定观察周期再决定正式准入。串关只由合资格、未闭售、不同比赛的方向生成，不凑二串或三串。
