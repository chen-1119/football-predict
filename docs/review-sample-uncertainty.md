# 复盘样本不确定性（2026-09-07）

## 范围

正式/参考复盘的已核验玩法与时间窗口，在命中数/已结算数下增加可键盘展开的 95% Wilson 区间。公式依据 [NIST Wilson interval](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)，固定双侧 z=1.959963984540054。

只描述在各场独立、命中概率相同假设下的样本不确定性。折叠时仍展示假设及“非未来预测”，展开说明未校正日期/联赛相关性。不是配对模型优势检验，不用于准入或晋级，不改变命中数、历史方向、模型概率及正式门槛。

- 输入必须来自通过完整账本和玩法逐日对账的当前选择器；不从分页赛事列表反推。
- 使用实际整数计数重算，不相信服务端附带的 hitRate。
- 无样本、缺失/非法计数、本版本分组缺失、玩法分组缺失、研究影子均不显示区间。
- 0/1 和 1/1 不产生 NaN 或虚假零宽区间；50/100 约40.4%–59.6%，1/2 约9.5%–90.5%。这些是公式测试例，不是线上战绩。

## 验证

`verifyReviewDashboard.cjs` 检查数值参考、对称性、样本规模、边界和输入隔离以及真实 TSX 文案；`verifyReviewDashboardBrowser.cjs` 检查中英文三尺寸、键盘展开、时间切换和无样本隐藏；`verifyFullAppEvidenceBrowser.cjs` 检查完整应用路由中2场合成账本显示9.5%–90.5%。浏览器仅使用合成 HTTP 数据，不能替代生产视觉验收。
