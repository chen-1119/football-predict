## 两层合同

1. `auditFrozenDecisionMarket`读取原公开记录对应的哈希绑定特征/模型证据，核对赛事、玩法、盘口、完整三项报价、公开方向的SP与签名提取项。按运行时公钥登记表重新验签，不信任已有`eligible`布尔值。要求源观测≤收到≤原特征捕获≤原决策≤原记录<截止≤开赛。没有原快照，不取当前盘口补写。
2. `auditFrozenReferenceMarket`另外要求既有冻结版本/选择回执、可信官方结束状态、非VOID、合法整数比分和与原参考结算一致，再计算同场同玩法的公开方向和赔率基准命中。整数Sporttery HHAD使用原冻结让球，其他让球合同不混入。

基准固定为三项十进制赔率倒数按比例归一化后最大项；相同赔率严格按预声明`1 / X / 2`顺序处理，单列平手数，不按赛果挑选。只比较同一配对子集，并提供双方命中/仅公开命中/仅基准命中/双方未命中的四格计数。

整份传入账本先校验；损坏/重复/孤立证据令报告失败，不能先筛掉坏行缩小分母。全部传入历史按原统一赛事身份/业务日/冲突规则对账，合格配对+排除必须等于该输入的原参考结算总数。旧回执缺失、同一赛事副本证据缺失/冲突时保持不可配对，不回填。报告含逐日/逐玩法分组、主排除原因、逐赛事哈希追溯和输入文件SHA。输出必须为工作树outputs下未存在的普通路径，或系统临时目录中新建的football-reference-pair-report-*专用目录；拒绝父级链接。真实CLI测试使用后者，不向只读候选源码树写文件。
