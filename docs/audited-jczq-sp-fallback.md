# 已核验竞彩页面SP作为备用价格输入

## 为什么需要本轮改动

2026-09-19T02:32:04.425Z的仓库sync-meta记录官方直连HAD/HHAD报价均为0，保留65场500来源比赛。该记录是仓库自动同步产物，不是生产数据库验收。PR28此前修复了决策ID竞态和前端误隐藏，但仅接受sporttery:had标签的价格选择仍会拒绝所有500来源输入。

本轮明确扩展的是**报价来源准入策略**：允许从指定500竞彩页面实际采集、在PostgreSQL中可追溯的HAD SP转录作为备用价格输入。不把任意500标签/欧赔当竞彩SP，不改变旧“已验证正式”资格，不把第三方赛果当官方赛果。

## 运行路径

现有runMarketCollector调用sync500Data.parseRows，HAD来自nspf的data-sp字段。

`采集器 -> normalizeRows -> market_observations/market_latest + market_collector_runs -> signalBridge -> externalSignals.bookmakerOdds.had.lotterySpReceipt -> 本轮prospectiveForecastInput -> 统一决策 -> 单场/2串1/3串1`

- 新规范化HAD记录增加固定的500-jczq-had-copy-v1契约标记；HHAD不纳入本次改动。标记不包含时间，不破坏相同报价的去重。
- bridge读取观察与对应成功采集运行的来源、URL、原始响应SHA256、时间和内容哈希。来源仅限HTTPS trade.500.com下的jczq公开页面；当前记录还必须是sporttery bookmaker的had。
- 未标记旧缓存、缺失/失败采集记录、来源路径不合格或内容哈希不一致，不得到转录凭证，继续保持普通参考数据。
- 已核验转录保存为500.com:jczq:HAD，officialDirect=false。不会把source改成sporttery，页面也明确显示“500竞彩页面转录”。
- 接入前再次校验来源比赛ID、开赛/事件时间、主客队名称、完整三项报价、实际停售、未来时间与15分钟报价时效。别名不进行模糊放宽。
- 直连和转录各自携带完整价格与时间；按有效观察时间选择，同一时刻优先直连。
- 当前轮模型和凭证一起传递；不从已冻结父记录借用稍后的报价，也不覆盖父记录的旧模型时间/概率。

## 凭证的证据边界

receiptHash是检测序列化/传递后修改的摘要，**不是竞彩网签名、源站授权或独立第三方认证**。信任边界仍是既有受控的原生采集与数据库写入路径。

acquisitionRunId/acquisitionBodySha256属于该状态首次出现时的成功采集。observedAt来自该状态最近一次真实采集确认的market_latest.updated_at，并须等于观察的last_seen_at。它可能晚于首次采集；不声称首次原始响应哈希就是最后一次响应哈希。读取缓存、页面刷新、采集失败均不刷新该时间。

不从旧文件快照倒填标记或凭证。旧采集代码生成的缓存必须等待升级后的**一次真实成功采集**后才能进入本路径；仍遵守源站退避/cooldown，不强行重置冷却期。

## 不变的业务规则

2串1原始SP>=2.50，3串1原始SP>=5.00。继续采用统一模型向量唯一首选，不为凑SP换方向，不依赖旧BEST/recommend标签，不改模型/训练权重。已有冻结记录与原始时间不改，官方结果可信性/结算规则不放宽。实际有效场次不足或概率/SP不完整，不能用虚构值填满组合。

## 前端

价格来源随决策和冻结组合保存；单场、每条组合腿和展开版本详情都显示来源。旧记录没有来源字段时明确显示历史来源信息不可用，不补造成直连。新转录记录的前端解析还校验凭证和价格/事件/时间一致性。
