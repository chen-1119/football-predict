# 发布验证进程收尾提速（2026-09-09）

## 已定位的问题

五个验证器使用 `Promise.race(exit, timeout)` 收尾。进程先退出时，落败的 3 秒或 5 秒计时器没有取消，仍会拖延验证器退出；SIGKILL 发出后也没有等待 `close` 再删除夹具。访问码三个独立场景还会同时保留三台测试服务器直到整组结束。

本次统一使用 `scripts/stopVerificationChild.cjs`：只接受验证器自己创建的 ChildProcess，不接受 PID 或系统服务；正常退出立即取消两个计时器；超时升级 SIGKILL 后仍等待管道关闭；无法确认关闭时返回失败并保留夹具。访问码场景逐个收尾，最多保留一台场景服务器。全部业务断言保留。
