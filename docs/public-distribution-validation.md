# Pages 与服务器数据验证边界

2026-09-07 集成 UI 时实际执行 `validate:data`，当前 Git 快照声明私有未结算归档14场，但 Git 仓库没有该私有文件，产生两处计数不符。Pages 工作流原先使用相同命令，因此无法独立验证这类快照。

- 默认 `validate:data` 仍为服务器完整验证：读取私有归档，核验数量、过期状态及与公开列表/历史的身份不重叠。数据同步工作流继续使用它。
- 仅 Pages 显式使用 `validate:data:public`（`--public-distribution`）：不读取或打包私有档案；仍核验全部公开数据、静态资源保护和两处归档声明为相同非负安全整数。
- 公共范围报告 `privateArchiveVerified=false`，真实归档数量为null，声明数量另列，不能据此通过服务器私有归档验收。
- 不把私有归档放进 Git、静态目录或包中；未更改任何比赛或统计快照。

实际验证器的内存文件替身测试覆盖缺失/无效/矛盾归档计数、默认服务器缺档拒绝、公共范围不读意外私有文件、服务器坏归档拒绝、合法零归档和公共赛果缺失仍拒绝；该回归也加入 production-readiness。此修复不跳过生产门禁，不代表新 UI 已完成线上部署。
