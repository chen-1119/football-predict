# 下一批推荐卡展示契约建议

本文件是待总控与 02 数值任务集成的接口建议，尚未实现、测试或上线。字段语义须由现有服务契约确认；本批不改公共类型、服务、概率计算或资格判定，不填造真实比赛预测。

| 展示区域 | 所需语义 | 展示规则 |
| --- | --- | --- |
| 比赛身份 | 同场 ID、主客队、联赛、开赛时间 | 北京时间；历史默认日期不称今天 |
| 主／平／客对照 | 同一决策的三个概率、校准状态、相同版本 | 三列同等视觉权重；缺项显示 —；参考／影子／正式明确标识；不由赔率逆推正式概率 |
| 冻结 SP | 同一决策官方 SP、来源及授权等级、报价观测时间 | 与赛程快照 SP 分开；无法证明官方来源时不标官方；时间未知明确显示未核验 |
| 赛前依据 | 有来源的赛前输入、观测时钟、采纳状态 | 复用 prematchEvidencePresentation 和稳定 clock hooks；迟到／冲突／未采纳证据不作当时可用依据 |
| 关键缺失与风险 | 未知伤停、阵容等待／采集失败、xG 来源状态、过期报价等 | 伤停未知显示 —；阵容待官方发布与采集失败分开；缺失 xG 显示来源状态，不补造数值 |
| 展示状态 | 服务提供的参考／等待资料／可发布状态及原因 | 可发布状态由服务判定；服务缺状态时显示等待核验，界面不自行提升资格 |
| 冻结版本 | 截止时间、实际决策时间、发布时间、decisionId／冻结版本 | 首屏显示截止时间；展开可查同场完整版本；缓存重观察时间不替代决策时间 |

将三个判断分别呈现，不以一个绿色状态替代全部：

1. 模型可靠性：校准与验证状态；无可靠模型时保留真实资料，概率如已有只能按服务给定参考身份展示。
2. 数据质量：来源、完整度、鲜度、冲突／迟到状态，明确哪些输入缺失。
3. 单场资格：报价是否合格、截止是否通过、服务判定原因；未取得资格不凑正式推荐。

等待场景用真实原因说明：例如“阵容待官方发布”“伤停来源暂不可用”“报价时间未核验”。这些仅为文案类别，不是任何真实比赛的当前判定。单场历史回归由 05 任务提供，不在 UI 层计算或修改。

下一批验收需服务提供真实或明确标注的隔离边界样本；覆盖参考、影子、等待资料、可发布、截止已过和缺失字段。完整权益页面需有效登录后验收。本批已验证的是公开赛程、公开比赛资料及原有公开复盘概率展开。
