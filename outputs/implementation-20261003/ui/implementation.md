# 推荐状态展示实际接入

## 本轮修改

`RecommendationEvidenceFacts` 已增加紧凑状态栏，出现在 `MatchDetail` 原有的三个证据展示位置，无需新路由。

- 未取得发布记录：显示「等待资料」，解释等待的是发布记录；保留原有其他只读参考区块。
- 已有发布记录：显示「分析参考」，继续展示同一冻结记录的全部三项概率、SP、时间和版本。
- 正式推荐资格：当前服务端合同仅支持 `unvalidated`，显示「尚未通过模型验证」；未提供则明确「正式资格未提供」。参考筛选通过不会转成正式推荐。
- 服务端资格原因使用已知枚举映射，未知原因以通用提示显示，不透传内部错误文本、URL 或令牌。
- 移除旧的两张重复验证卡；必要的单场参考资格保留为一行。下一步说明压缩为「查看冻结赔率及资料缺口；新资料须经新决策采用。」

`recommendationReadinessPresentation.ts` 只做展示转换，没有调用 `qualifyRecommendationOutput` 构造晋级布尔，没有新阈值，没有修改概率、业务数据合同、发布规则或白名单。
