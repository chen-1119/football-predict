# 0.2.0 开发记录

本轮只开发和本地验证，不执行服务器安装、数据库迁移、定时器启用或网站发布。

- 采集窗口继续固定为北京时间今天和明天、网站内未开赛且身份对应准确的比赛。
- 阵容 30 分钟尚未公布时增加 20/10 分钟有限补查；取到完整名单后停止后续补查。90/60/30 分钟正常核对保留，允许发现临场更正。
- 每轮默认 12 页面、480 秒；阵容优先、取消后不继续开页，未处理任务下轮继续。
- 联赛对应发现按北京时间日期及配置保存进度，多轮补齐全部页面后才发布完整对应表；跨日、配置改变或超过 6 小时的旧进度自动失效。
- 本轮复用一个比赛只读连接池。观测导出按最多 500 场分批，每批单事务两次 SELECT，保持场次和事件版本隔离。
- 网站读取层新增受限 JSON 读取、当前赛事校验及鉴权 HTTP 处理函数。公开结果移除采集域名、路径和 provider 标识，保留事实、缺失状态与更新时间。
- 明确区分暂时性网络失败与访问阻断。前者受原有次数和间隔限制，后者暂停；doctor 可查看暂停状态。
- 联赛发现同样保留失败原因并执行有限退避；已暂停任务在访问数据库和浏览器前退出。
- 导出批次间检查中断与时间预算；取消后保留旧文件，避免发布部分数据。
- 公开文本补充 Windows 网络共享路径清洗，避免暴露内部主机与目录。

仍未完成真实服务器浏览器取数验收、实际网站 API 挂载和目录权限配置。赔率自动采集未实现，默认已验证联赛配置仍为英超；其他联赛需要逐项核实页面并配置。以上能力不能解释为已经全面替换网站数据源。
