# 网站读取接口开发契约

代码位于 `website-reader.cjs`，已经实现文件读取、数据校验、公开字段投影和 HTTP 处理函数；本轮不在网站挂载路由，不启动监听端口。

## 调用方式

`createWebsiteReader({ exportPath, readFixture, maxBytes, now })` 返回异步 `read(siteMatchId)`。`exportPath` 必须是服务器配置中的绝对路径，不能来自请求参数。`readFixture(id)` 由网站提供，读取当前权威比赛对象，不能返回离线测试样本。默认最大 10 MiB，使用同一文件句柄 stat/read，支持采集器原子替换导出。

`createWebsiteHandler({ ...以上参数, authorize })` 返回异步 `(req, res, siteMatchId)`。网站必须传入实际登录鉴权回调，且只有明确返回 `true` 才可读取文件或比赛；支持 GET/HEAD，其他方法返回 405。没有配置路径返回 `disabled`；文件缺失、损坏、权限不足仅返回通用 `unavailable`，不回传本地路径或异常堆栈。

建议未来挂载到已有鉴权下的 `/api/v1/matches/:id/prematch-evidence`。**路由保护规则也需要同时注册**；当前网站保护规则只匹配单段比赛详情，不会自动覆盖这个新子路径。不能因为父详情路径已鉴权就假设新路径受保护。

## 公开返回

```json
{
  "matchId": "sporttery_123",
  "eventVersion": "2026-09-12T14:00:00.000Z",
  "status": "ok",
  "updatedAt": "2026-09-12T12:59:00.000Z",
  "predictionEligible": false,
  "sections": {
    "injuries": {
      "status": "source_empty",
      "observedAt": null,
      "lastAttemptAt": "2026-09-12T12:58:00.000Z",
      "previousValue": false,
      "data": null
    },
    "lineup": {
      "status": "source_empty",
      "observedAt": null,
      "lastAttemptAt": "2026-09-12T12:58:00.000Z",
      "previousValue": false,
      "data": null
    }
  }
}
```

上面仅说明字段形状，不是真实观测；有效伤停列表必须含经过校验的记录，不能把空数组作为“已证明无伤停”。阵容有效时 `data.teams` 含双方、阵型、教练、首发和替补，首发必须双方各 11 人。

`status=ok` 仅代表当前导出与比赛通过校验，页面还需读取各 section 的状态。`previousValue=true` 表示保留上次成功内容但最新一次未成功，必须同时显示旧值时间及当前状态，不能把它显示成新抓取结果。`source_empty` 表示来源未公布，`missing` 表示没有证据；`stale/ineligible/conflict` 不展示成当前有效数据。

页面按用户要求，在单场详情的“数据与分析”展示这些字段；推荐列表只显示比赛、方向、SP、命中/未命中或待赛果。公开 DTO 不含 `sourceUrl`、provider 比赛/球员 ID、原始采集路径和供应商名称；内部数据库完整溯源继续保留。

## 后续挂载前需要完成

1. 为网站进程只授权读取单独的导出 JSON，不授权浏览器 profile。
2. 绑定真实比赛读取和网站登录鉴权函数，并注册新子路由保护规则。
3. 详情页面消费接口，验证未配置、无数据、过期、更新失败和正常数据状态。
4. 在真实服务器用实际抓取结果验收。本包测试采用本地临时 JSON 与模拟回调，不证明生产挂载已完成。
